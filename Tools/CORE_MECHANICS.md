# Основные механики Ricochet Arena

Игровая логика полностью в Blueprint-графах. Python используется для создания
ассетов и проверки редактора. C++ и сторонние C++-плагины не добавлялись.

## Запуск и управление

Откройте /Game/RicochetArena/CoreMechanics/Lvl_RicochetPrototype и нажмите Play.
Если редактор был открыт во время генерации, откройте карту вручную.

- WASD — движение по арене, скорость 650 см/с, диагональ ограничена.
- Мышь — направление взгляда и оружия.
- Удержание ЛКМ — стрельба каждые 0.18 с.
- Касание микросхемы — её Value прибавляется к Microchips.
- HUD показывает управление и текущий баланс ресурсов.

На карте размещены пять микросхем и шесть стен для проверки отражений.

## Blueprint-ассеты

Все ассеты находятся в /Game/RicochetArena/CoreMechanics.

| Blueprint | Назначение |
| --- | --- |
| BP_RA_PlayerCharacter | Движение, прицеливание, стрельба, баланс ресурсов |
| BP_RA_PlayerController | Курсор и управление камерой |
| BP_RA_RicochetProjectile | Полёт, отражение, доступный после рикошета урон |
| BP_RA_RicochetWall | Стена с тегом RicochetWall |
| BP_RA_Microchip | Подбираемый ресурс с настраиваемым Value |
| BP_RA_HUD | Подсказки и счётчик |
| BP_RA_GameMode | Назначение игрока, контроллера, HUD |

Снаряд использует сферическую swept-коллизию и ProjectileMovement:
1800 см/с, без гравитации, коэффициент отражения 1, трение 0, движение в XY.
На восьмом отражении или через 6 секунд снаряд удаляется.
Только удар о актор с тегом RicochetWall включает HasRicocheted.
Удар о другой блокирующий объект удаляет снаряд.

## Подключение будущих роботов

- При смерти робота создавайте BP_RA_Microchip с положительным Value.
- GetRobotDamage у снаряда возвращает 0 до рикошета и Damage (25 по умолчанию) после.
- Будущий получатель урона должен вызывать GetRobotDamage перед нанесением урона.
- Снаряд игнорирует Pawn игрока. Тестовый робот использует WorldDynamic; для других типов врагов возможны
  отдельный объектный канал либо обработка overlap с исключением владельца.
- Тестовый робот с HP и уроном после рикошета реализован; выпадение, волны и улучшения ещё не реализованы. См. Tools/TEST_ROBOT.md.
- AddMicrochips принимает только положительное количество.

## Проверки и автоматизация

В PowerShell из корня проекта выполните:

    ./Tools/test_core_runtime.ps1

Отдельная карта Lvl_CoreAutomation проверяет поведение без окна и автоматически
завершает процесс. Не используйте её для обычной игры.

Проверки: прицеливание, ограничение стрельбы, запрет отрицательного пополнения,
запрет подбора посторонним актором, начисление Value, нулевой урон до отражения,
движение, подбор по overlap, флаг и счётчик рикошета, отражение с сохранением
скорости и доступный урон после отражения.

Отчёты находятся в Saved/Automation/CoreMechanics; игровой лог — Saved/Logs/CoreRuntime.log.

build_core_mechanics.py и verify_core_mechanics.py — одноразовые генераторы.
Они отказываются перезаписывать существующие ассеты.
run_core_automation.ps1 включает официальный EditorToolset Epic для создания графов.
Игровые Blueprint не требуют EditorToolset или Python во время игры.
Существующие ассеты шаблона TopDown сохранены.
